2. Bereitstellung der Website

Beim Aufruf dieser Website verarbeitet der Hostinganbieter technisch erforderliche Verbindungsdaten, insbesondere IP-Adresse, Zeitpunkt des Abrufs, angeforderte Datei, übertragene Datenmenge und Informationen zum verwendeten Browser. Die Verarbeitung ist erforderlich, um die Website auszuliefern und die technische Sicherheit zu gewährleisten.

3. Cookies und Analyse

Diese statische Website setzt von sich aus keine Analyse- oder Marketing-Cookies ein und verwendet keine Tracking-Dienste.

4. Kontakt per E-Mail oder Telefon

Wenn du per E-Mail oder telefonisch Kontakt aufnimmst, werden die von dir übermittelten Daten zur Bearbeitung deiner Anfrage verarbeitet.

5. Portfolio-Bilder

Die auf dieser Website dargestellten Portfolio-Bilder werden zusammen mit der Website auf dem verwendeten Hostingdienst bereitgestellt. Beim Laden der Bilder wird daher keine Verbindung zur bisherigen Squarespace-Website benötigt.

6. Hosting über GitHub Pages

Diese Website wird über GitHub Pages bereitgestellt, einen Dienst von GitHub. Beim Besuch einer GitHub-Pages-Website wird die IP-Adresse der Besucher nach Angaben von GitHub zu Sicherheitszwecken protokolliert und gespeichert. Darüber hinaus können technisch erforderliche Verbindungs- und Nutzungsdaten verarbeitet werden, soweit dies für die Bereitstellung und Sicherheit des Dienstes erforderlich ist.

Weitere Informationen zur Datenverarbeitung durch GitHub findest du in der Datenschutzerklärung von GitHub: GitHub-Datenschutzerklärung.
